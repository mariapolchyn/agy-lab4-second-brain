# Персональний Second Brain (Local-First Knowledge Base)

Локальна, автономна система ведення та структурування навчальних конспектів для студента, спроєктована за методологією **PARA**, принципами **Zero Vendor Lock-in** та підтримкою двонаправлених посилань (`[[Wikilinks]]` і `Backlinks`).

---

## 🚀 Інструкція запуску

Застосунок розроблено на чистому Node.js без використання сторонніх npm-бібліотек або важких фреймворків.

### Передумови
* Встановлений [Node.js](https://nodejs.org/) версії `18.x` або вище.

### 1. Запуск сервера застосунку
У терміналі в корені проєкту виконайте:

```bash
# Запуск через Node.js напряму:
node src/server.js

# Або за допомогою npm-скрипту:
npm start
```

Після запуску відкрийте браузер за адресою:
👉 **[http://127.0.0.1:3000](http://127.0.0.1:3000)**

### 2. Запуск автоматизованих тестів
Проєкт містить повне покриття юніт-тестами сховища та e2e-тестами HTTP API:

```bash
# Запуск юніт-тестів сховища (індексація, зв'язки, пошук, безпека):
node tests/test-store.js

# Запуск інтеграційних тестів HTTP REST API:
node tests/test-server.js

# Або запуск усіх тестів однією командою:
npm test
```

## 📂 Організація даних за методологією PARA

Усі навчальні матеріали зберігаються у вигляді чистих файлів Markdown (`.md`) з метаданими у форматі **YAML Frontmatter** всередині каталогу `notes/`:

```text
notes/
├── Inbox/       # 📥 Нерозібрана черга: сирі думки, швидкі чернетки з лекцій
├── Projects/    # 🚀 Поточні завдання з дедлайнами: лабораторні роботи, курсові проєкти
├── Areas/       # 🎯 Довгострокові сфери відповідальності: дисципліни семестру, карти знань (MOC)
├── Resources/   # 📚 Довідкові матеріали: специфікації ISA, алгоритми, формули, шпаргалки
└── Archives/    # 📦 Завершені предмети, здані лабораторні минулих семестрів, застарілі дані
```

### Формат навчальної нотатки:
Кожен файл містить машиночитаний заголовок та людиночитаний вміст:
```markdown
---
title: "Назва теми"
created: "2026-11-22T14:00:00+02:00"
updated: "2026-11-22T15:00:00+02:00"
tags:
  - архітектура-кс
  - апаратні-прискорювачі
status: "active"      # inbox | active | archived
type: "concept"       # lecture | lab | concept | resource | moc | project
source: "Лекція / Підручник"
---

# Назва теми
Зміст нотатки підтримує зв'язки [[Назва іншої нотатки]] та математичні формули LaTeX:
$$ C = A \cdot B $$
```

## ⚙️ Системні обмеження та архітектурні рамки

1. **Zero External Dependencies:**
   * Серверна частина працює виключно на вбудованих модулях Node.js (`node:http`, `node:fs/promises`, `node:path`, `node:url`).
   * Клієнтська частина реалізована на чистому Vanilla HTML5, сучасних CSS-змінних та ванільному ES6+ JavaScript без бандлерів і трансляторів.
2. **In-Memory індексація:**
   * Спроєктовано для швидкої обробки навчальної бази обсягом **500–1000 нотаток**.
   * Граф зв'язків (`forward links` та `backlinks`), повнотекстовий індекс та словники тегів підтримуються в пам'яті процесу, забезпечуючи час відгуку **< 5 мс**.
3. **Обмеження середовища:**
   * Робота розрахована на одну робочу станцію (локальний ПК/ноутбук) студента.
   * Синхронізація та історія змін базуються на локальному Git-репозиторії.

## 🔒 Політика приватності та безпеки (Data Governance)

* **100% Offline & Local-first:** Усі знання, конспекти та вкладення зберігаються виключно на локальному накопичувачі користувача. Застосунок не робить жодних мережевих запитів за межі вашого пристрою.
* **Без зовнішніх API та секретів:** Для роботи системи не потрібні API-ключі, платні підписки, сторонні LLM-сервери чи хмарні бекенди.
* **Прив'язка до Localhost:** Вебсервер прив'язаний виключно до адреси `127.0.0.1`. Прослуховування загальнодоступних інтерфейсів (`0.0.0.0`) заборонено, що унеможливлює доступ до бази знань із локальної мережі (наприклад, університетського Wi-Fi чи гуртожитку).
* **Захист від Path Traversal:** Усі дискові операції валідуються методом канонізації шляхів (`resolveSafePath`). Спроби доступу за межі каталогу `notes/` за допомогою `../` або абсолютних шляхів негайно блокуються.
* **Повна відсутність телеметрії:** Жоден рядок коду не збирає аналітику, поведінкові фактори чи логи використання.
* **Zero Vendor Lock-in:** Конспекти залишаються стандартними файлами CommonMark. Навіть при повному видаленні програми всі матеріали можна відкривати й редагувати у VS Code, Obsidian, Vim чи будь-якому іншому редакторі.

3. Сувора заборона вигадувати джерела чи факти (нульові галюцинації).

5. **Заборона самовільного переміщення чи видалення файлів** без явного підтвердження користувачем.
