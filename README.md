# Навчальні нотатки (Second Brain)

Проста вебсторінка для створення та збереження навчальних конспектів і нотаток у браузері без сторонніх залежностей.

## 🚀 Стек технологій
- **HTML5**: Семантична та доступна розмітка (`aria-*`, семантичні теги, форма з валідацією).
- **CSS3**: Чистий мінімалістичний стиль із підтримкою адаптивності для мобільних пристроїв.
- **JavaScript (Vanilla)**: Логіка валідації, захист від XSS через безпечну роботу з DOM, збереження даних у `localStorage`.

## 🎯 Критерії приймання (Acceptance Criteria)
1. **Поля форми**: Заголовок (обов'язкове), Предмет/Категорія (обов'язкове), Теги (необов'язкове, розділені комами), Зміст (обов'язкове).
2. **Валідація**: При спробі надіслати порожні обов'язкові поля з'являються зрозумілі повідомлення про помилки, поле підсвічується, надсилання блокується.
3. **Збереження даних**: Нотатки надійно зберігаються у `localStorage` браузера і не зникають після оновлення або закриття сторінки.
4. **Відображення списку**:
   - Нові нотатки одразу з'являються у списку зверху без перезавантаження сторінки.
   - Відображається кількість збережених нотаток.
   - Відображається пустий стан (empty state), якщо нотаток немає.
5. **Видалення**: Будь-яку нотатку можна видалити зі списку з підтвердженням дії.
6. **Безпека**: Введений користувачем текст екранується (через `textContent`), запобігаючи XSS-атакам.

## 🧪 Спосіб локальної перевірки

### Варіант 1: Пряме відкриття у браузері
1. Відкрийте файл `index.html` у будь-якому сучасному браузері (Chrome, Firefox, Edge, Safari):
   - Подвійний клік на `index.html` або перетягніть файл у вікно браузера.

### Варіант 2: Локальний HTTP-сервер
Якщо у вашій системі встановлено Python або Node.js:
- **Python**:
  ```bash
  python -m http.server 8000
  ```
  Після цього відкрийте у браузері: `http://localhost:8000`

- **Node.js (npx)**:
  ```bash
  npx serve .
  ```

## 🔍 Сценарії тестування для ручної перевірки
1. **Перевірка валідації**:
   - Натисніть кнопку «Зберегти нотатку» без заповнення форми.
   - Переконайтеся, що під кожним обов'язковим полем з'явилося червоне повідомлення про помилку.
2. **Створення нотатки**:
   - Заповніть Заголовок: `Основи Git`, Предмет: `DevOps`, Теги: `git, vcs, terminal`, Зміст: `git init, git commit, git push`.
   - Натисніть «Зберегти нотатку».
   - Переконайтеся, що нотатка з'явилася у списку, поля форми очистилися, а лічильник став `1`.
3. **Перевірка персистентності**:
   - Оновіть сторінку (клавіша `F5` або `Ctrl+R`).
   - Переконайтеся, що нотатка залишилася у списку.
4. **Видалення нотатки**:
   - Натисніть кнопку «Видалити» на картці нотатки, підтвердіть дію.
   - Переконайтеся, що нотатка зникла і знову відображається повідомлення «Поки що немає жодної збереженої нотатки».
