# Лабораторна робота 1: Реалізація матричного множника на FPGA

## 1. Мета та завдання
Спроєктувати апаратний модуль множення матриць фіксованого розміру $4 \times 4$ для елементів формату Fixed-Point (Q8.8) з використанням мови опису апаратури Verilog HDL для цільової платформи Xilinx Artix-7 (XC7A35T).

---

## 2. Архітектура модуля
* **Обчислювальне ядро:** Використання апаратних DSP48E1 слайсів для реалізації швидких операцій MAC (Multiply-Accumulate).
* **Інтерфейс передачі даних:** Шина AXI4-Stream для взаємодії з хост-процесором через контролер прямого доступу до пам'яті (DMA).
* **Конвеєризація:** 3-ступеневий внутрішній конвеєр для забезпечення тактової частоти не менше 150 МГц.
