# Курсовий проєкт: Проєктування VLIW-процесора для обробки сигналів

## 1. Загальна постановка завдання
Розробка мікроархітектури та системи команд (ISA) спеціалізованого VLIW-процесора (Very Long Instruction Word) для задач швидкого перетворення Фур'є (FFT) та цифрової фільтрації (FIR-фільтри).

---

## 2. Специфікація процесора
* **Ширина інструкції:** 128 біт (4 слоти операцій по 32 біти кожен):
  - Слот 0: Арифметико-логічний блок ALU 0 (підтримка операцій із насиченням).
  - Слот 1: Арифметико-логічний блок ALU 1.
  - Слот 2: Блок завантаження/збереження (Load/Store Unit, LSU) з підтримкою циклічної адресації.
  - Слот 3: Блок переходів та керування конвеєром (Branch Unit).
* **Регістровий файл:** Кластеризований регістровий файл (2 банки по 16 регістрів розрядністю 32 біти).
* **Принцип диспетчеризації:** Статичне планування компілятором. Відсутність апаратного виявлення структурних та інформаційних конфліктів.
