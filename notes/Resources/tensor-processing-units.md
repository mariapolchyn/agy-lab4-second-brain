# Тензорні процесори (TPU) для машинного навчання

## 1. Архітектурне призначення
Google Tensor Processing Unit (TPU v1–v4) є класичним прикладом предметно-орієнтованого процесора (ASIC), спроєктованого виключно для інференсу та тренування глибоких нейронних мереж.

На відміну від універсальних процесорів x86/ARM, TPU відмовляється від складних блоків позачергового виконання (Out-of-Order execution), передбачення переходів (branch prediction) та дворівневих кешів на користь масивного паралелізму обчислювальних блоків.

---

## 2. Матричний обчислювальний блок (MXU)
Серцем архітектури TPU є блок Matrix Multiply Unit (MXU). 

> [!IMPORTANT]
> MXU реалізований як двовимірна матриця процесорних елементів розміром $256 \times 256$, яка працює за принципом, описаним у нотатці: [[Систолічні матриці в апаратних прискорювачах]].

### Ключові характеристики MXU:
* Обробка 65 536 операцій множення з накопиченням (MAC) за один такт.
* Робота з цілочисельним форматом INT8 (у TPU v1) та плаваючою комою bfloat16 (у наступних поколіннях).
* Застосування потоку даних Weight-Stationary, де ваги моделі попередньо завантажуються в матрицю.

---

## 3. Організація пам'яті (Scratchpad Memory)
Замість апаратно-керованих кешів інструкцій та даних TPU використовує явно адресовану буферну пам'ять (Unified Buffer, 24 МБ SRAM):
1. Програмне забезпечення (компілятор XLA) повністю контролює рух даних.
2. Відсутність промахів кешу (Cache Misses) гарантує детермінований час виконання (Strict Latency SLA), що критично для дата-центрів.
