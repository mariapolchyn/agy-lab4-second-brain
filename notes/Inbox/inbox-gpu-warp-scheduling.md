# Варпи та планування потоків у GPU SIMT

## Сирі нотатки з пари (потребують структурування та перенесення в Areas)
* GPU не виконує окремі потоки поодинці: апаратний планувальник об'єднує потоки у групи по 32 штуки, які називаються **варпами (Warps)**.
* Усі 32 потоки варпу виконують одну й ту саму інструкцію в кожен такт часу (модель SIMT — Single Instruction, Multiple Threads).
* **Warp Divergence (Розходження варпів):**
  - Якщо всередині варпу є розгалуження `if-else`:
    1. Спочатку виконується гілка `if` для потоків з активною маскою (решта потоків блокуються).
    2. Потім виконується гілка `else` для іншої частини (перші блокуються).
  - Результат: подвійна затримка виконання! Потрібно уникати дивергенції у внутрішніх циклах обчислень.
* **Latency Hiding (Приховування затримок пам'яті):**
  - Замість величезних кешів GPU використовує нульову вартість перемикання контексту між варпами.
  - Поки один варп очікує дані з VRAM (до 400-800 тактів), планувальник миттєво запускає інший варп, готовий до обчислень.
